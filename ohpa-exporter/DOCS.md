# OHPA Data Exporter

Experimental standalone app. Start manually, open Web UI, select model and sensor mappings, confirm physical meters and operating status, choose research profiles and 24/72/168 hours, download ZIP. No separate HA token. No background collector. Review every file before sharing; email manually to ohpa@hagenback.nl. The mail link cannot attach the ZIP automatically. No automatic sending.

Data is pseudonymous, not anonymous. Relative times, installation ID and technical measurements may still reveal patterns. Comfort needs separate confirmation. No presence or contact events, entity IDs or absolute timestamps included. Only selected profiles are exported. Recorder retention/freshness limits apply. Direct measured flow or cumulative volume is required for VFM/PWM; select separately metered power and explicit BUH boundary for VFM. Other profiles are exploratory: coverage is not proof of valid measurements or causal effects. Intervention records use relative minutes and numeric before/after values. Mapping can be saved locally; consent is reset each session. Single indoor zone, 7-day maximum. Preview shows actual ZIP manifest, coverage and up to three sample rows per CSV; download uses the identical cached ZIP (15 minute token, one use). Review full downloaded file before sharing. Known suffix proposals need user confirmation; Bommer/Leejow and real Supervisor testing pending. Full row-by-row preview, overlap detection, richer installation metadata, research inbox and secure receiver are future work.

# Open HeatPump Analytics — experimental

Install and start, then Open Web UI. Optionally show in sidebar. No HA URL, long-lived token, admin password, MCP secret or exposed port required. Supervisor supplies Core API credentials. Configure sensors and verify units and boundaries. Rooms and dwelling profile are optional. Registry access may be limited; manual mapping remains available. Data persists in /data; back up before updates. This mode is ingress-only, without external MCP. Check logs and report version/revision for issues; never share credentials.

Real Supervisor and ARM runtime validation is pending despite successful multi-architecture publishing. See [installation guide](https://github.com/sin7ek/open-heatpump-analytics/blob/main/docs/installation.md) and [user guide](https://github.com/sin7ek/open-heatpump-analytics/blob/main/docs/user-guide.md).
